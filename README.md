 
## Features 
- Login with BCrypt password hashing 
- Dashboard with KPI cards and JFreeChart 
- Full CRUD for Spotify tracks 
- Export to CSV 
- 8 JUnit 5 tests passing 
## Setup 
1. Install MySQL 9.5 
2. Run schema.sql in MySQL Workbench 
3. Open SpotifyManager in Eclipse 
4. Run Main.java 
## Technologies 
- Java 21, Swing, JDBC 
- MySQL 9.5, BCrypt 
- JFreeChart 1.0.19 
- JUnit 5
